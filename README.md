## Folder Structure

The workspace contains two folders by default, where:

- `src`: the folder to maintain sources
- `GrafoEtiquetado`: contiene las clases de la estructura de un diGrafo etiquetado
- `EstructurasAux`: contiene estructuras auxiliares que se utilizan para la construccion de otras estructuras mas relevantes
